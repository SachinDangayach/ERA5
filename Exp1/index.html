Activations exist for a reason.

Four claims about why deep nets need the pieces they have. Each tab trains real models in your browser and shows you the picture, not just the number.

Claim

A model with no nonlinearity can only ever draw a straight boundary. It cannot separate two rings, one inside the other, no matter how it's trained.

Build

300 noisy 2D points: an inner ring (class 0) and a concentric outer ring (class 1). Not linearly separable by construction. Two models see the identical data — (a) one linear layer + sigmoid, (b) the same layer with a ReLU hidden layer inserted before it.

The boundary picture is the money shot: a straight cut through a ring gets roughly half the points by luck, ~55%. Add one ReLU layer — no new data, no new features — and the same optimizer bends that cut into a closed curve, ~99%. Only the activation changed.

Claim

Stack five linear layers and you still have one linear map — composition of linear functions is linear. A 5-layer net with no activation is exactly as strong as 1 layer, and just as unable to split the rings.

Build

The same ring data as S1-1, seen by three models: (a) 1 linear layer, (b) 5 stacked linear layers with no activation between them, (c) the same 5 layers with a ReLU inserted after each hidden one.

Five linear layers multiply down to one matrix — literally, above. Same data, same optimizer, and the 1-layer and 5-linear-layer boundaries are indistinguishable. Insert a ReLU between each pair of layers and depth suddenly starts doing work: the ring gets solved.

Claim

Train an embedding table on nothing but "predict the next token" and tokens that behave alike start to look alike — even though category was never a training signal.

Build

A toy grammar over 8 tokens — animals (cat, dog, cow), fruits (apple, mango), verbs (eat, chase, see) — generating sentences like "cat chase dog" and "cow eat mango". An 8-dim embedding table feeds a softmax over the vocabulary, trained only to predict the next token in the stream.

Proof

– same-category NN

Project the 8 learned embeddings to 2D (PCA) and the three categories separate into three regions — no category label was ever shown to the model.

Nobody told the model that cat and dog are alike. It only ever saw "predict the next word." Same-category tokens land near each other because they play the same distributional role in the grammar — that's the whole idea behind word embeddings.

Claim

A high-capacity net can memorize a tiny dataset — train loss to ~0 — while doing barely better than chance held out. Give it more data at the same capacity, and that gap closes.

Build

A noisy 2D classification task (wiggly true boundary, 12% label noise). The same over-parameterized net (2→32→32→1, ~1,200 weights) trains from scratch at three sizes — n = 20, 200, 2000 — each with its own 400-point held-out test set.

– gap @ n=2000

Same net, same optimizer, same number of steps — the only thing that changed across these three panels is how much data it had to fit. The gap between train and test is capacity looking for signal and finding noise instead; more data is what gives it signal to find. Data is everything.
