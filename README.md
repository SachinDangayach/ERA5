# ERA5

Experiment log for fine-tuning a model. Each `ExpN/` folder is a self-contained experiment with its own README covering what was tried, how to run it, and what came out of it. This file is the index — one line per experiment, updated as new ones are added.

## Experiments

| 1 | [Exp1](Exp1/README.md) | Why activations matter — four in-browser proofs (nonlinearity, depth without nonlinearity, embeddings from next-token prediction, memorization vs. generalization) | Done |

## Conventions

- One folder per experiment: `Exp1`, `Exp2`, ...
- Each experiment folder has its own `README.md` with setup, how to run, and results/findings.
- Add a row to the table above when a new experiment starts; update its status as it progresses (`Planned` / `In progress` / `Done`).
